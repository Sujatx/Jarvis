Face swap
=========

The Matrix scene surfaces a face inside the falling code while Jarvis speaks.

By default it uses a procedurally generated placeholder face (no file needed).

To use your own portrait, drop an image here named exactly:

    face.png

Any portrait works — the loader "contains" it into the glyph grid, crops to the
bright content, and normalizes brightness, so lighting/size don't matter much.
Best results: a face that is clearly brighter than its background (a headshot on a
dark or plain backdrop). Reload the page after swapping.
